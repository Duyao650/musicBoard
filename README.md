# KeyLight Music Keyboard

A browser-based music keyboard with piano mapping, waterfall visualization, sustain, transposition, classical UI, and optional local video backgrounds.

## Local development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The production build is generated in `dist`.

## GitHub Pages deployment

This project includes a GitHub Actions workflow at `.github/workflows/deploy.yml`.

After pushing to the `main` branch, enable GitHub Pages with:

- Source: GitHub Actions

GitHub will build and publish the site automatically.
